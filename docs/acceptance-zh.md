# Frame Note 验收标准

当前状态：2026-09-14 上传、版本切换与定位评论阶段已验收；用户再次回复“可以，继续吧”，版本对比阶段验收通过。只读分享已实现并通过 347 项单元测试、88 项数据库测试及 21 条浏览器流程，等待用户验收；完整项目尚未验收通过，本记录不授权 GitHub 发布。

## 项目用途

把设计稿、具体位置上的评论和版本对比放在同一个评审空间中。
它不是绘图软件，不负责生成设计稿，也不是 Signal Roadmap 的换色版本。

## 最终应能实际操作的流程

1. 在本地启动应用和独立数据库，不登录云平台即可开始隔离演示。
2. 创建演示文稿，上传本地图片或选用项目自带的原创示例图片。
3. 修改画面名称与说明，调整顺序；刷新后内容和顺序保持不变。
4. 进入演示模式，用键盘或触摸切换画面。
5. 创建分享链接，在另一个浏览器会话中确认分享权限生效。
6. 在设计稿具体位置添加评论，回复、解决并重新打开讨论。
7. 上传同一画面的第二个版本，并排或拖动遮罩对比。
8. 切换版本、改变浏览器尺寸后，评论仍关联正确版本与图片位置。
9. 查看真实产生的评审活动和活跃查看者状态，不使用虚构活动。
10. 验证过期演示、撤销分享、只读访问、越权操作和上传限制。

## 验收证据

- 桌面和手机尺寸下的实际运行截图。
- 真实数据库和文件存储上的完整浏览器操作测试。
- 可复现的安装、迁移、种子数据、测试和构建说明。
- 失败时有明确提示，不以静态界面或假成功状态代替功能。

## 版本对比阶段操作清单（已验收）

1. 打开本地预览，进入已有演示；会话已过期时使用 `Start a private demo` 新建测试空间。
2. 上传一张图片，再用 `New version image` 为同一画面上传修改稿。
3. 点击 `Compare versions`，用 `Left version`、`Right version` 选择两个版本。
4. `Side by side` 并排查看两稿；手机窄屏会改为上下排列。
5. 点击 `Overlay`，拖动画面分界线，或聚焦 `Reveal left version` 滑块后使用方向键；Home/End 显示完整右稿/左稿。
6. 图片按相同比例从左上角对齐；尺寸不同的空白不代表内容丢失。程序不会拉伸图片来伪造重合。
7. 点击 `Back to review` 回到原先版本；进入对比前尚未发送的评论草稿应仍在。切换画面或评审版本则切换评论上下文。
8. 页面刷新后图片与版本仍在，但不承诺保存未发送草稿或当前对比布局。

## 只读分享阶段操作清单（待验收）

1. 打开 http://127.0.0.1:4310，进入演示文稿；已有会话过期时新建私有演示并上传测试图片。
2. 向下找到 `Share presentation`，选择 `Link duration`（1 小时或 24 小时），点击 `Create view-only link`。
3. 点击 `Copy link`，或手动复制 `New share link` 输入框中的完整地址。链接只在创建后显示一次；刷新或切换演示文稿后不能再次获取原链接全文，可新建链接。
4. 在这台电脑的 Chrome 无痕窗口粘贴完整地址。无需登录，能够查看该演示文稿的画面及新旧版本，但没有评论、上传或编辑权限。
5. 返回所有者窗口，点击对应链接的 `Revoke link`。访客窗口应在下一次检查时（通常约 5 秒）显示 `This link is unavailable.`，不再显示图片。
6. 网络或图片暂时读取失败时，应看到重试提示，而不是假装保存或加载成功。

链接覆盖这一个演示文稿的现有和后续版本，任何持有完整链接的人都能查看。有效期不会超过当前演示及创建者的有效期。每个演示文稿最多创建 20 条链接，已撤销的也计数。撤销不能收回已下载的图片或截图。

当前链接仅在本机使用，不能发到另一台电脑或手机当成线上网站访问。访客评论、完整演示模式、永久账号与数据恢复尚未实现。请使用可丢弃的测试图片；演示退出或过期后不能恢复原空间访问。
