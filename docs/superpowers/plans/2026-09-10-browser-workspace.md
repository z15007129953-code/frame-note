# Frame Note Browser Workspace

> Use subagent-driven-development for backend implementation and independent reviews. This executes the previously user-approved product and local-only delivery scope.

**Goal:** An actual local browser journey: isolated demo session, create presentation, upload screen, select image, upload a new version, reload persisted results, sign out.

**Architecture:** Next App Router / React; opaque HttpOnly demo cookie backed by hashed database tokens. Thin route handlers derive actor IDs exclusively from a live session, enforce same origin on writes and bounded payloads, then call existing review/image repositories. Private images are read through permission-checked routes with no-store. No cloud service, public repository, or email account is needed.

**Design brief:** Restrained, precise, attentive; a physical gallery worktable with artwork as the focus. Daytime light neutral canvas tinted toward olive; dark olive action/focus. No marketing dashboard, invented collaboration activity or fake buttons. Narrow left presentation list, central image stage, visible image upload/new-version form. Mobile stacks the list and stage without losing functionality. Empty states describe the next action. Five fixed rem type sizes,4pt spacing,44px controls. Font defaults Inter/DM Sans/IBM Plex Sans rejected; catalog candidates Manrope (geometric labels/headings) and Hanken Grotesk (humanist reading/forms), loaded locally via Fontsource. Existing .impeccable.md supplies confirmed user/audience context. Craft references: spatial,typography,interaction,responsive.
