# Frame Note

## Design Context

Source: user-approved Product Lab Suite specification, section 6.2 and section 9;
the user delegated detailed visual choices. Recorded through impeccable teach.

### Users

Designers presenting work, collaborators reviewing revisions, and stakeholders
leaving precise feedback. Desktop is the primary review workspace; phone users
must still navigate screens and read, place, resolve, and reopen comments.

### Brand Personality

Restrained, precise, attentive. Make feedback feel considered and contextual.

### Aesthetic Direction

A neutral review workspace in which the uploaded artwork dominates. Use a light
editor shell for daytime team review; a configurable presentation backdrop belongs
to the screen, not to an unrelated global theme. Avoid copying the community
noticeboard interface from Signal Roadmap, generic metric dashboards, and heavy
card containers around every action. Final typography and tokens are selected
during impeccable craft, before UI implementation.

### Design Principles

1. Artwork first; controls frame it without competing with it.
2. A comment always makes its screen, version, location, and resolution visible.
3. Read-only access, edit permission, and share access are explicit.
4. Comparison must preserve image aspect ratios and clearly identify each version.
5. Pointer interactions have keyboard alternatives; mobile preserves critical tasks.

WCAG AA contrast, visible focus, reduced motion, and labelled controls are release
requirements. No fabricated collaboration activity or user counts.
